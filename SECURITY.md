# Security Policy

Please report security issues privately rather than opening a public issue.

Email: **hello@runproven.ai**.

Include what you found, steps to reproduce, and impact if known. We'll acknowledge receipt
and follow up with a fix timeline.

## Notes on scope

- Bundled personas (`personas/*.yaml`) carry fictional facts only (names, emails, phone
  numbers) for exercising forms — they are not real user data.
- Never commit real API keys, tokens, or `.env*` files (other than `.env.example`) in a
  report or a pull request; redact them if they appear in logs you share with us.
